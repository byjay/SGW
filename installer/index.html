⭐ Seastar Groupware

사내 직원용 — 사원번호 로그인 / 연차 / SEDMS / 활동 알림
💡 이 페이지는 Seastar Groupware 전용 설치기입니다.
SDU 학습 자동화 (SDU Master) 확장과 별개입니다.
🚀 사내 자동 설치 다운로드 (ZIP)

압축 풀기 → .bat 더블클릭 → UAC [예] → 30초 자동 완료

📋 설치 방법

  1. 위 ZIP 다운로드 → 우클릭 [압축 풀기]
  2. Install-SGW.bat 더블클릭
  3. UAC(파란창)에서 [예] 한 번 클릭
  4. 모든 브라우저 닫고 다시 열기 → ⭐ 아이콘 자동 표시

✨ 핵심 기능

사원번호 자동 로그인 영구 세션 (재로그인 불필요) 연차 신청 빠른 접근 SEDMS 빠른 접근 활동 푸시 알림 (4종) 10개 페이지 빠른 메뉴 30분 자동 업데이트 8개 Chromium 브라우저
⚠ Windows Defender 경고가 뜨면 [추가 정보] → [실행]을 눌러주세요. 사내 인증서 미서명 .bat은 첫 실행 시 항상 경고가 뜹니다 (안전합니다).
