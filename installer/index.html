🚀 사내 자동 설치 (원클릭)

Install-SGW.bat 더블클릭 → UAC [예] → 30초 자동 완료

압축 풀기 불필요 · 9개 브라우저 정책 자동 등록 + 결과 검증

대안 — .bat 차단 시 PowerShell 1줄

회사 PC에서 SmartScreen이 .bat 다운로드를 막을 때:
시작 → "PowerShell" 우클릭 → [관리자 권한으로 실행] → 아래 한 줄 붙여넣기 → 엔터

iwr -UseB https://sgw-install.pages.dev/installer/Install-SGW.ps1 | iex

(코드 클릭 시 전체 선택됩니다 · UAC 자동 상승됨)

⚡ 강제 업데이트 (원클릭 v1.0.5)

Force-Update-SGW.bat 더블클릭 → UAC [예] → 자동 완료

압축 풀기 불필요 · 브라우저 정책만 갱신 (확장 설정/세션은 그대로)

📋 설치 방법 (3단계)

  1. 위 Install-SGW.bat 다운로드 → 더블클릭
  2. UAC(파란창)에서 [예] 한 번 클릭
  3. 모든 브라우저 닫고 다시 열기 → ⭐ 아이콘 자동 표시

✨ 핵심 기능

사원번호 자동 로그인 영구 세션 (재로그인 불필요) 연차 신청 빠른 접근 SEDMS 빠른 접근 활동 푸시 알림 (4종) 10개 페이지 빠른 메뉴 30분 자동 업데이트 8개 Chromium 브라우저
