# Seastar Groupware

A modern, high-performance groupware solution built with Vite, React, and Tailwind CSS. Featuring real-time collaboration tools, messaging, and administrative controls.

## Features

- **Modern Dashboard**: Clean and intuitive UI for daily tasks.
- **Messaging & Chat**: Private and group communication channels.
- **Board & Community**: Public bulletin boards for company-wide announcements.
- **Calendar & Scheduling**: Manage events and appointments seamlessly.
- **Admin Tools**: Comprehensive user and system management for administrators.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/byjay/SGW.git
   cd SGW
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

### Build and Deployment

To create a production build:
```bash
npm run build
```

The app is configured for automatic deployment to Cloudflare Pages via GitHub Actions.
